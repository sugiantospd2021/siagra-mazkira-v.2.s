# App Guru RA Mazkira Imani

Aplikasi manajemen pembelajaran untuk guru RA Mazkira Imani - Barito Kuala.

## Fitur
- Multi-role: Guru, Kepala RA, Admin
- Wizard RPP 5 langkah
- Catatan Anekdot anak
- Observasi Harian (BB/MB/BSH/BSB)
- Format Penilaian & Raport otomatis
- Validasi RPP + Tanda Tangan Digital
- Backup & Restore data

## Teknologi
- HTML + CSS + JavaScript (Single Page App)
- Data lokal di browser
- Hosting: Vercel
